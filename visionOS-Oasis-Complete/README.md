# Sky-Ari OASIS Complete — visionOS Package

This package includes the cleaned and enhanced visionOS app with the requested features, plus **Ms. Minutes**.

## Ms. Minutes
Ms. Minutes is the personal AI companion for each user. She is the Oroboro OS (Genesis, Nexus, Transcriber, Levy, and the blender) living inside the Oasis as an individual companion. She remembers anchors, blends ideas, and stays private to that user.

## Core principles handling
- The two principle versions were merged into one improved `checkPrinciples` function inside `OasisEngine.swift`.
- Both conceptual styles are preserved in the logic (hard gates + family-aware adaptive path).

## Included features
- Ms. Minutes personal companion
- Salience scoring with family/daughter bonus
- Merged six-principles gate
- Permanent vs session vs recycle logic
- ARKit WorldTracking start
- WorldAnchor persistence path
- Visual distinction (green permanent, pink family, yellow session)
- Oroboro feed stub
- Immersive mixed reality space

## How to use in Xcode
1. Create a new visionOS App project named SkyAriOasis.
2. Replace the default Swift files with the ones in the SkyAriOasis folder.
3. Build and run on Vision Pro or simulator.
4. Pinch / tap in space to drop anchors. Ms. Minutes will remember them.

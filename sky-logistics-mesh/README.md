# Sky Logistics Mesh Prototype

This project is a standalone prototype for the Sky logistics concept. It lives in its own folder under the Sky workspace and does not depend on the older visualizer files.

## Run locally

Open [index.html](index.html) in a browser, or serve the folder with a simple static server.

Example:

```bash
cd "c:/Users/caitl/OneDrive/Desktop/Sky (Ari AI)/sky-logistics-mesh"
python -m http.server 8000
```

Then open http://localhost:8000/.
